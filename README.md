### Objective

The objective of this project is to practice and demonstrate web automation testing using **Selenium WebDriver with Python**. The tests automate common web testing scenarios, such as verifying page elements, interacting with web components, and detecting broken links and images.

This project is intended to strengthen practical skills in **Selenium, Python, test automation, element locating, and web application testing**.

---

## 🔍 Scope of Testing

### In Scope

The following functionalities are covered:

* Web UI automation using Selenium WebDriver with Python
* Locating and interacting with web elements
* Testing buttons, dropdowns, links, images, and other UI components
* Verifying expected behavior using assertions
* Detecting broken links and broken images
* Automating repetitive functional test scenarios

### Out of Scope

* Performance
* load testing
* Security testing
* Database testing
* Mobile application testing
* Backend and server-side testing
